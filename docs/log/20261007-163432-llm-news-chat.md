## Gotchas
- Mutation check M2 first "passed" because my `sed` never matched (`ruff format` had turned `‹` escapes into literal characters); a
  mutation run that changes nothing looks exactly like a test that cannot fail. Check the mutation applied (grep/diff) before trusting a green run.
- The frontend mutation "default opt-in true" survives: it is an equivalent mutant (the reset effect also runs at construction and sets it false).
  The reset itself is covered by the symbol-change test.
- Caught while writing the component: history turns were capped at 2000 characters on the server, but an answer of 600 tokens can exceed that,
  which would have 422'd the *next* question. Server cap raised to 4000 and the client truncates to the same.
- FastAPI closes the request's DB session before a streamed body finishes, so the generator must not use it; all DB work is done before streaming.
- The system prompt itself contains the literal `<data>` / `</data>`; tests that count delimiters must look at the final user message only.
- Calling `mount()` twice in one Angular test fails ("test module already instantiated"); use two tests.
- The news section's cache key `("news", symbol)` in `company_cache` is a coupling to `api/symbols.py`; `test_news_is_fetched_once_for_the_news_section_and_the_chat` guards it.
- Nothing is committed: other sessions still have uncommitted work in this checkout (`docs/TODO.md`, `scripts/make_seed.py`).
