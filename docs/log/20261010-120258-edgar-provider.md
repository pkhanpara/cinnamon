# SEC EDGAR provider (ADR 0017)

## Goal
First two items of the "Research data: SEC EDGAR + FMP" TODO section: decide how EDGAR fits next to Finnhub, and add a tested EDGAR client. Nothing calls it yet; `fundamentals.py` wiring is the next item.

## Changes
- `docs/adrs/0017-sec-edgar-fundamentals-provider.md`: opt-in via `SEC_USER_AGENT`, precedence (EDGAR companyfacts over Finnhub as-reported for 10-K items, original 10-K over 10-K/A, Finnhub as fallback and still the source for metric/peers/insiders), throttle and caching rules.
- `backend/app/providers/base.py`: `Fact`, `CompanyFacts`, `SecFilingsProvider` Protocol.
- `backend/app/providers/edgar.py`: `EdgarProvider`
  - `cik_for` (ticker normalization BRK.B -> BRK-B, validation before any request, `company_tickers.json` in a 24 h stale-on-error `TTLCache`, broken maps never cached)
  - `get_company_facts` (annual 10-K/10-K/A `FY` facts in USD, USD/shares, shares; bad rows dropped; newest first)
  - slot-reservation throttle (>= 1/8 s apart, fails past 10 s)
  - 50 MB decoded body cap, HTTP errors -> ProviderError, 404 -> None.
- `backend/app/providers/__init__.py`: `get_edgar_provider()`, None unless `SEC_USER_AGENT` is set and valid (printable ASCII, <= 200 chars, contains `@`); one instance per process.
- `backend/app/config.py` `sec_user_agent`; `.env.example` entry.
- `backend/tests/test_edgar_provider.py` + `tests/fixtures/edgar/*.json` (fabricated values in SEC's shape): 44 tests, all on `httpx.MockTransport`, fake clock/sleep, no network.

## Decisions
- No default User-Agent: SEC wants the operator's own contact, and one shared string would get every install blocked together.
- Own throttle instead of `SlidingWindowLimiter`: its `retry_after` is whole seconds, too coarse for an 8/s limit.
- The provider does not cache companyfacts: the caller will store them in `fundamentals_cache` like other fundamentals.
